OPIS

Modul Profil je namenjen upravljanju polj uporabniškega profila po meri.

NAMESTITE/ODSTRANITE

Posebni ukrepi niso potrebni, sledite standardnemu postopku namestitve – ekstrahirajte mapo /profile v imenik ../modules. Namestite modul prek Admin -> System Module -> Modules.

Podrobna navodila za namestitev modulov so na voljo v Operacijski priročnik XOOPS

NAVODILA ZA UPORABO

Za nastavitev tega modula morate:

  • Konfigurirajte svoje nastavitve za modul (glejte 'Nastavitve') in opcijsko blok profila, če ga nameravate uporabljati (glejte 'Bloki').
  • Uredite obstoječe kategorije ali dodajte nove.
  • Uredite obstoječa polja ali dodajte nova. Tukaj lahko določite, katera polja bodo vidna v kateri kategoriji in ali bodo vidna med registracijo uporabnika.
  • Določite vrstni red korakov registracije.
  • In končno, lahko nastavite dovoljenja za posamezna polja - katera je mogoče urejati in katera je mogoče iskati.

Ukrepi proti neželeni pošti

Če želite zmanjšati neželeno pošto, naredite naslednje:

  • pojdite na modul Protector v Admin, pojdite na Preferences in nato na dnu, na to možnost: "Ustavi neželeno pošto na forumu" Preverja podatke POST glede na pošiljatelje neželene pošte, registrirane v bazi podatkov www.stopforumspam.com.
    Nastavi na "Ban the IP (brez omejitev)"

  • v /class/captcha/config.php se prepričajte, da je način nastavljen kot "text":

    return $config = array(
    'disabled' => false, // Onemogoči CAPTCHA
    'mode' => 'text', // privzeti način, lahko izberete 'text', 'image', 'recaptcha' (zahteva ključ api)
    'name' => 'xoopscaptcha', // ime captcha
    'skipmember' => res, // Preskoči preverjanje CAPTCHA za člane
    'maxattempts' => 10, // Največje število poskusov za vsako sejo
    );

  • V modulu Profil pojdite na Administrator in v osnovnem koraku, ki se nahaja na:
    /modules/profile/admin/step.php?id=1
    nastavite "Shrani po zaustavitvi" na "Ne"


  • V nastavitvah profila nastavite možnost »Uporabi Captcha po drugem koraku registracije« na »Da« (to je privzeto)
